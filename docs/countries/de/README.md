## GovAPI Core use case

Select the current FIT-Connect 2 contract and the supported SDK. Prepare the TEST assignment and synthetic statement, get a receipt and read the authorized event in the case. Set the SDK version, event code and application ID. The current plugin is the navigator and mock. [Moving to FIT-Connect 2](https://docs.fitko.de/fit-connect/docs/major-release/fit-connect_2/)

## Bell use case

First, use the Event Log and show the event log through a common interface, and you need a self-assembler if you have a separate incoming source or a user process that doesn't close the log, and access to the central state mail is checked separately.

## Free and open-source alternatives

Officially, SDK Java, .NET and JavaScript, examples, and TEST have been published. It already covers transport and event analysis. The enservice bus platform is not open source. [SDK FIT-Connect](https://docs.fitko.de/fit-connect/docs/sdks/overview/)
