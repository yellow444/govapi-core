# Global directory of government services and APIs

The index covers **198 jurisdictions**, including **193 UN member states** and five additional GTMI jurisdictions. The index includes separate technical references for 58 jurisdictions and [review results for the other 140](#review-results-for-140-jurisdictions), including source code availability.

The baseline uses World Bank GTMI 2025 indicators I-19 for online public service portals, I-4 for government service buses, and I-3 for interoperability frameworks. A portal or a service bus does not establish API access for an external system. GTMI links are starting points. No live government API calls were made for this review.

**Reference available** links to the API and access section. **Reviewed** links to country-level findings for the other 140 jurisdictions. Case status, fiscal document processing, and message delivery are listed separately. Tax and customs interfaces are identified by sector.

## Review results for 140 jurisdictions

Slice from 26 November 2026: For each item previously described only by the GTMI indicators, official documentation is searched; the table shows the confirmed transaction, the applicable role and the source code availability; the phrase “not confirmed” means that the documented interface of the required operations is not found in the sources reviewed; the contract can be available after registration or on request to the service owner.

Application processing status, fiscal document status, and message delivery receipt have different meanings. Departmental and industry interfaces are defined with boundaries. Public examples, SDKs, and platform source codes are labeled separately. Published specifications do not, by themselves, confirm source availability or the right to work with real data.
