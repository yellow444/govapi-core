# Norway · NO

Sources verified November 25, 2026.

## Portal and interfaces

Altinn Dialogporten brings together the dialogues of different departments, Altinn Correspondence has a guide for system vendors, describes the authorization and test interfaces. [OpenAPI Dialogporten](https://docs.altinn.studio/en/dialogporten/reference/openapi/) · [Correspondence for Supplier](https://docs.altinn.studio/en/correspondence/getting-started/developer-guides/systemprovider/)

## Core and Bell use cases

Core can show the registration of the test system and the assignment of permissions. Bell is worth checking in the narrow process of delivering correspondence to the local work system. Dialogporten itself already covers the aggregation and metadata of dialogs. The GovAPI Hub plugin is not yet available.

## Free and open-source alternatives

Dialogporten source under MIT. There's a system vendor demo application. Access to a particular recipient's data depends on registration and the rights granted. [Code.](https://github.com/altinn/dialogporten) · [Example](https://docs.altinn.studio/en/authorization/guides/system-vendor/system-user/democlient/)
