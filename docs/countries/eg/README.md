# Egypt · EG

Sources verified November 25, 2026.

## Electronic invoices and checks

The ETA tax office documents the filing, packet ID status check and callback on the completion of processing. For callback, the receiving ERP/POS pre-registers the address. [ETA integration schemes](https://sdk.invoicing.eta.gov.eg/integrationpractices/) · [Connection.](https://sdk.invoicing.eta.gov.eg/start/)

## Use case and limitations

For Core, this is an industry example of a full-cycle transaction. For Bell, check whether you need to keep the callback separate from the confirmation and account status in the accounting system. These are fiscal circuit events. General administrative correspondence is not confirmed here. The official SDK site contains technical documentation, the publicity of the full-platform code is not established.

The GovAPI Hub plug-in is not yet available.
