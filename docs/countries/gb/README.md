# United Kingdom · GB

Sources verified November 25, 2026.

## Portal and interfaces

GOV.UK Forms accepts forms. GOV.UK Notify provides email, SMS and email delivery APIs as well as trial mode. [GOV.UK Forms](https://www.forms.service.gov.uk/about) · [API Notify](https://www.notifications.service.gov.uk/using-notify/api-documentation) · [Trial](https://www.notifications.service.gov.uk/using-notify/trial-mode)

## Core and Bell use cases

Core can show the transfer of the result of one procedure to Notify and read the delivery status. Bell will require a separate incoming stream from the procedure owner. Notify is already closing the sending and tracking of the delivery.

## Free and open-source alternatives

Email via GOV.UK Notify is free for authorized users. There are source codes for GOV.UK Forms. The permission for the hosted service and the terms of the channel are checked separately. [Tariffs](https://www.notifications.service.gov.uk/pricing) · [Forms code](https://github.com/govuk-forms/forms)
