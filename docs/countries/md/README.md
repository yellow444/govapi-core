## Portal and interfaces

MConnect is used for sharing, MNotify is used for sending and recording notification records, and MNotify has documented staging, certificates, and query examples. [Platform catalogue](https://egov-moldova.github.io/egov4dev/en/platforms/) · [MNotify Connection](https://egov-moldova.github.io/egov4dev/en/guides/mnotify/integration-development/)

Core can prepare the registration of the test IC and parsing one operation. For Bell, check whether the API only displays notifications related to the connected sender and what interface the external recipient needs in the selected process.
