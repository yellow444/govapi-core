# Poland · PL

Sources verified November 25, 2026.

## Portal and interfaces

e-Doręczenia provides legally relevant digital delivery, published API and test environment access procedure for public and non-public organizations, and for new integration should be checked the current version of the UA API. [Interfaces](https://www.gov.pl/web/e-doreczenia/interfejsy-api) · [Test Wednesday](https://www.gov.pl/web/e-doreczenia/srodowisko-testowe-dla-podmiotow-publicznych-i-niepublicznych)

## Core and Bell use cases

Core can prepare the entrance to TEST and the training of one shipment. For Bell, check the safe import of the incoming one, separately recording the receipt and the action that changes the status of the message at the operator.

## Free and open-source alternatives

Third-party PHP SDK published under MIT. Production acceptance of the SDK and the presence of an analogue with ready-made free command delivery are not confirmed. [PHP SDK](https://github.com/b44x/edoreczenia-php)

## Open questions

Access to the test box, the operator’s version of the contract and the legal value of the recipient’s actions.
