# Finland · FI

Sources verified November 25, 2026.

## Portal and interfaces

Suomi.fi Messages delivers official messages. REST APIs, technical connection procedures, and testing instructions have been published for organizations, and the agency announced the deactivation of old interfaces on December 31, 2026. [REST API](https://kehittajille.suomi.fi/services/messages/technical-description/rest-api) · [Connection.](https://kehittajille.suomi.fi/services/messages/deployment/technical-deployment) · [Duration of migration](https://kehittajille.suomi.fi/events/suomi-fi-messages-old-apis-will-be-shut-down-on-31-december-2026-ensure-your-organisation-takes-the-necessary-action)

## Core and Bell use cases

Core can organize a REST connection and verify the delivery of a single test message. For Bell, it must first determine which notifications and responses are available to the connected system and who is eligible to represent the recipient.

## Free and open-source alternatives

The public documentation and REST description are freely available, and the source of the full service and the ready-made free third-party client are not confirmed by this card.
