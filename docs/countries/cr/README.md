# Costa Rica · CR

Sources verified November 25, 2026.

## Electronic accounts

The Ministry of Finance publishes an API for submitting an electronic document, requesting a result and callingback, the authenticity of the participant and obtaining credentials are checked according to the requirements of the tax authority. [API specification](https://www.hacienda.go.cr/docs/ComprobantesElectronicosAPI.html) · [Document formats](https://www.hacienda.go.cr/docs/ANEXOS_Y_ESTRUCTURAS_version_4.1.pdf)

## Use case and limitations

For Core, it's a test of filing, status, and linking a response to a document; for Bell, it's accepting a permissioned processing message and storing the ID in a local archive. It's an industry scenario. It's an ability to read general government notices, and the publicity of the service's source is unconfirmed.

The GovAPI Hub plug-in is not yet available.
