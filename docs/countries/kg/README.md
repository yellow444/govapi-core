# Kyrgyzstan · KG

Sources verified November 25, 2026.

## Portal and interfaces

| System system | What's up | Access and source |
|---|---|---|
| Tunduk Portal | Electronic public services | The applicant's office. [Portal](https://portal.tunduk.kg/) |
| SMEA Tunduk | Interaction of systems via X-Road | The operator has an order of connection of participants and a directory, the rights are issued for specific services. [Connection.](https://tunduk.gov.kg/en/be-user) · [Catalogue](https://catalog.tunduk.kg/) |

## GovAPI Core use case

Select a service with a local participant, get a contract description and test procedure, name of the role, supplier and consumer, schema version and response format, start with a local template and let the user check one structured result. GovAPI Hub plug-in is not available yet.

## Bell use case

In the directory, search for events of the selected service. Separately check the status, notification channel and conditions for providing this data to external IP. Universal access to portal notifications is not confirmed.

## Free and open-source alternatives

The operator publishes .NET training adapters with a client example. The independent X-Road Test Client is licensed by MIT. The source of the entire portal is not installed in these materials. [Example of Tunduk](https://wiki.tunduk.kg/doku.php?id=dotnet-adapters-demo) · [X-Road Test Client](https://github.com/petkivim/x-road-test-client)

## Open questions

Testing conditions for non-state IP, the specific service available, and the authority to read the response.
